# QueueCare 🏥

QueueCare is a simple clinic management system that helps manage patient appointments and the live waiting queue.

### Features

* 📅 Book and manage appointments
* 👨‍⚕️ View doctor and patient details
* 🔄 Track appointment status
* 📊 Dashboard with appointment information
* 🗄️ Store appointment data using SQLite
* ⚡ FastAPI backend with a simple web frontend

### Tech Stack

**HTML • CSS • JavaScript • Python • FastAPI • SQLite**
